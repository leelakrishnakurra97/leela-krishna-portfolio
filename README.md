## 🌟 Overview & Highlights

This repository contains the complete source code for my personal web portfolio. It is engineered with a modern **Cyber Glassmorphism** dark aesthetic, interactive smooth animations, dynamic text typing, project filtering capabilities, modal previews, and complete mobile-responsive layouts.

### 🎯 Key Features

- **Cyber Glassmorphism Dark Theme**: Custom dark color system featuring glowing cyan (`#00f2fe`) and electric purple (`#7f00ff`) accent gradients.
- **Dynamic Typing Effect**: Interactive typing hero section showcasing key technical roles.
- **Interactive Project Showcase**: Filterable project gallery with category tags (AI & ML, Software Testing, Web Development) and modal detail overlays.
- **Academic Education Timeline**: Chronological journey showcasing B.Tech at VIT Vellore (2024–2028), Class XII (94.90%), and Class X (9.20 CGPA).
- **Technical Arsenal & Progress Visualization**: Visual progress bars and pill badges for Python, C, JavaScript, HTML5/CSS3, Software Testing, QA workflows, and spoken languages.
- **Interactive Contact Form & Quick Actions**: Functional client-side form validation, copy-to-clipboard email helper, direct mail links, and GitHub profile connections.
- **Fully Responsive**: Optimized across desktop displays, tablets, and mobile smartphones.

---

## 🛠️ Technology Stack

- **Markup & Structure**: HTML5 (Semantic HTML, ARIA accessibility, SEO OpenGraph Meta Tags)
- **Styling & Aesthetics**: Vanilla CSS3 (CSS Variables, Flexbox/Grid, Glassmorphism `backdrop-filter`, Keyframe animations)
- **Scripting & Interactivity**: JavaScript (ES6+, DOM Manipulation, IntersectionObserver, Async Event Handlers)
- **Typography & Icons**: Google Fonts ([Outfit](https://fonts.google.com/specimen/Outfit), [Fira Code](https://fonts.google.com/specimen/Fira+Code)), [Font Awesome 6.4](https://fontawesome.com/)

## 🚀 How to Run Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/leelakrishnakurra97/leela-krishna-portfolio.git
   cd leela-krishna-portfolio
   ```

2. **Open in Browser**:
   - Double click `index.html` to open it in your default web browser, or use Live Server extension in VS Code.

## 🌐 GitHub Pages Deployment Guide

To deploy this portfolio live on GitHub Pages:
1. Go to repository **Settings** on GitHub: `https://github.com/leelakrishnakurra97/leela-krishna-portfolio/settings`
2. Navigate to **Pages** in the left sidebar.
3. Under **Build and deployment** -> **Branch**, select `main` branch and `/ (root)` folder.
4. Click **Save**. Your site will be live at `https://leelakrishnakurra97.github.io/leela-krishna-portfolio/`!
